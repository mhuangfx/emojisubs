# Whisper models

The app looks for `ggml-<size>.bin` files in this folder (for example `ggml-base.en.bin`,
`ggml-medium.en.bin`). Download them from the whisper.cpp model repository:

```bash
curl -L -o models/ggml-base.en.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.en.bin
```
